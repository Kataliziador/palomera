# Palomera

Aplicación de televisión para Android TV que los proveedores de internet
instalan en la caja de sus abonados.

- **[Aviso de privacidad](privacidad)** — qué recoge la aplicación, para qué, y
  cómo pedir acceso, rectificación o cancelación de tus datos.
- **[Código fuente](https://github.com/Kataliziador/palomera)** — la
  aplicación es software libre bajo GPL-2.0, derivada de
  [jellyfin-androidtv](https://github.com/jellyfin/jellyfin-androidtv). No está
  afiliada al proyecto Jellyfin.
